# Sebastián Ceciliano

Perfil dark de redes sociales. Paleta tomada del poster Grok Bot San José Workshop: negro, blanco, gris y acento teal.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Editar enlaces

Los placeholders viven en [`data/profile.ts`](data/profile.ts): nombre, bio y URLs de cada red.
